# Contributing

Thanks for helping improve this repository.

## Before opening a pull request

- Create a short-lived branch from `main`.
- Keep changes focused and easy to review.
- Never commit repository secrets, SSH private keys, public IP credentials, or Husarnet join codes.
- For Docker Compose changes, validate the file with `docker compose config` when possible.
- For workflow or Ansible changes, review the generated diff carefully before deploying to a server.

## Pull requests

Describe what changed, why it is needed, and how it was tested. Small documentation fixes are welcome and should remain separate from functional changes when possible.
